Platform icons (dark app-tile set supplied by the client, 256px WebP):
facebook, instagram, youtube, linkedin, whatsapp, tiktok, snapchat, pinterest, x, threads,
google, google-maps, google-ads, meta, google-analytics, google-search-console, google-tag-manager

To add or replace an icon:
1. Put the file here, e.g. telegram.webp (or .svg / .png)
2. In CONFIG (content3.js / index.html) add its id to `brandIcons`
3. If it is not .svg, add it to `brandIconFiles`, e.g.  telegram: 'telegram.webp'
